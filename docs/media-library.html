Media Library

Overview

The Media Library is a centralized storage and management system where all uploaded and AI-generated media files are displayed in one place. It allows users to upload, preview, search, share, update, and delete media files through a modern and responsive interface. All images uploaded by the administrator are automatically stored in the Media Library. Additionally, all content generated through Text-to-Image, Image-to-Image, and Image-to-Video modules is also automatically saved and displayed here, allowing users to easily access and manage all media files from a single location.

Dashboard

The Media Library dashboard displays all uploaded and AI-generated media files in a clean grid-based layout. Each media card shows the image preview, file type, file size, and quick action options for easy management.

The dashboard also includes:
  1. Search functionality for quick media lookup
  2. Multiple selection option for bulk actions
  3. Upload Media button for adding new files
  4. Quick actions on each media file: view, copy URL, share, update, and delete

Users can quickly manage media files or upload new content directly from the Media Library dashboard.

1. Upload Media

Click the Upload Media button to open the upload media modal.

The form includes:
  1. Upload Area : Drag and drop files or select images from the device
  2. Supported Formats : Upload supported image file types such as PNG, JPG, JPEG, WEBP, and GIF
  3. Multiple Upload Support : Upload single or multiple media files at once
  4. Upload Media Button : Submit and upload selected files to the Media Library
2. View Media

The View Media feature allows users to preview uploaded or generated media files in detail. After successfully uploading a file, users can hover over the media item in the Media Library and click on the Eye icon to open the preview. This action displays the selected image or video in a larger view

3. Delete Media

The Delete Media Icon allows users to permanently remove unwanted media files from the Media Library. When a user clicks the delete icon on any media item, a confirmation dialog appears asking whether they are sure they want to delete the selected media. This step helps prevent accidental deletion of important files.

4. Edit Name of the Media

The Edit Name of the Media feature allows users to rename their uploaded or generated media files directly within the Media Library. By hovering over a media item, clicking the edit icon, and entering a new name in the dialog, users can easily organize and identify their media assets.

5. Copy Media URL

The Copy Icon allows users to quickly copy the media file URL from the Media Library. By hovering over a media item and clicking the copy icon, the system automatically copies the direct URL of the image or video to the clipboard. This copied link can then be opened in a browser or shared across any platform such as chat, email, or social media, making it easy to reuse and distribute media content.

  • The Media Library stores all uploaded and AI-generated media in one place.
  • A Media can be viewed, copied via URL, edited or deleted
  • It provides easy search and management for all media files.
