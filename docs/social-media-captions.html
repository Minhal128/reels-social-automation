AI Captions

Overview

AI Captions is a specialized workspace for managing post captions. It provides creators with a centralized directory of reusable caption blocks, containing both AI-generated templates and manually drafted texts. These captions can be filtered, edited, and selected during composer workflows to maintain brand voice consistency across channels.

1. Captions Workspace & Counters

The **Captions Workspace** displays the caption list. In the header, stats cards track:

  • Total Saved: The aggregate count of captions saved in the database.
  • AI Generated: Captions generated using AI models.
  • Manually Written: Text drafts added manually by the team.
  • Active & Ready: Caption blocks marked with active statuses, making them available during post composing.

Shows the stats grid, keyword search bar, source filters (manual vs AI), and status dropdown filters.

2. Creating and Editing Captions

Clicking the Create Caption button opens the configuration modal. Users specify:

  • Caption Name: Friendly name for internal library cataloging.
  • Caption Text: The actual caption content (fully supports hashtags, mentions, and emojis).
  • Notes: Internal tags or descriptions explaining when or where to use this caption.
  • Status: Toggle between Active, Inactive, or Draft.
[Image Placeholder: Add / Edit Caption Modal Form]

Shows the fields for editing the caption body, applying internal notes, and setting workflow status toggles.

  • Keep pre-approved caption templates for marketing promos, campaigns, and standard bios.
  • Filter captions by creation source (AI vs manual) and scheduling readiness status.
  • Quick copy functionality to insert templates directly into the publisher composer.
