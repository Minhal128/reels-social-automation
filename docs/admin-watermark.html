Watermark Settings

Overview

The **Watermark Settings** panel allows administrators (and users under user-specific profiles) to configure a custom watermark design overlay to protect platform-generated images and videos. You can design an identity overlay using either text or brand image files, refine their styles dynamically, and view real-time changes on a live visual preview canvas.

1. Content Source Configuration

Configure what content to show as the watermark overlay:

  • Watermark Type: Toggle between Image and Text types.
  • Image Asset Selector: Opens the Media Picker modal to choose your logo or brand icon from the Media Library.
  • Text Input: Define custom branding text (e.g. © Reelease AI). You can configure font family, font weight, color (picker), styling (italic, underline), and text alignment.
2. Refine & Adjust Layout

Fine-tune how the overlay behaves on top of images or videos:

  • Position Anchor: Choose from grid anchors (e.g. Top-Left, Center, Bottom-Right) to pin the watermark position.
  • Sliders (Scale, Rotation, Opacity, Padding): Slider controls to scale the size, rotate angles, set transparency, or change spacing borders.
  • Blending Mode: Select standard canvas blending algorithms (e.g. Normal, Multiply, Overlay, Screen) to integrate the watermark organically with output color layers.
  • Tiling Switch: Repeats the watermark across the entire image/video canvas in a grid layout to maximize protection.
3. Live Canvas Preview

The middle canvas area provides a mockup image reflecting all settings modifications (position, styling, size, opacity, rotation, etc.) in real time. This ensures you can check exact visual results before applying changes globally.
