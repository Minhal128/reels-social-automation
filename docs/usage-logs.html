Usage Logs

Overview

The Usage Logs dashboard provides a detailed operational audit history of all AI activities performed on the platform. It tracks credit usage balances, generation prompts, and lets users download or manage completed digital media outputs.

1. Tracking AI Task Cards

All AI requests (images, videos, motions) are grouped as individual task cards containing:

  • Service Type: Indicates which tool initiated the action (e.g., Text to Image, Video Motion, Image to Video).
  • Status Badges:
    • Completed: The task completed successfully, showing a visual media preview.
    • Running: The model is currently rendering the outputs (displays a loading spinner).
    • Failed: The task errored during rendering (displays a failure alert icon).
  • Used Credits: Shows the exact amount of credits consumed by this specific execution task.
  • Input Prompt: Displays the generation prompt text, with a copy button for quick reuse.
  • Date & Time: Records the exact calendar date and timestamp when the job started.

2. Output Media Actions

For completed tasks, the preview window allows several actions directly from the logs card:

  • Play Video / View Image: Hovering over video tasks automatically plays the video stream. Click any completed media to open it in a new window tab.
  • Save to Media Library: Click the Save icon to copy the generated image or video asset directly into your platform's Media Library for future use in Social Publishing.
  • Download Media: Instantly download the original file format (PNG for images, MP4 for videos) directly to your local storage device.
3. Filtering and Search

The workspace includes standard query filters to quickly browse thousands of log items. Search logs by entering keywords found in your prompts, and browse historical data cleanly using pagination controls.

Key Points
  • Failed tasks do not permanently consume user credits; they are automatically restored to the user's balance.
  • Logs are displayed chronologically, showing your most recent AI generations first.
