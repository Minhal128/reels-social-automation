Image to Video

Overview

Image-to-Video converts one or multiple uploaded images into a dynamic video. Users can add multiple images, and the system animates and transitions between them based on the given prompt, motion style, or scene instructions.

It transforms static images into a continuous video sequence, blending them smoothly to create engaging and realistic motion content using AI-powered generation.

1. Image to Video Dashboard

The Image to Video dashboard provides an AI-powered workspace for transforming static images into animated videos. Users can upload a start image and an optional end image to create smooth visual transitions, motion effects, and cinematic animations using integrated AI providers.

The dashboard includes an Animation Instructions section where users can describe the desired motion, camera movement, transitions, animation style, visual effects, or cinematic behavior for the generated video. A built-in Prompt Library helps users quickly access predefined animation prompts and creative ideas for faster video creation workflows.

Users can customize multiple video settings including aspect ratio, video duration, generation mode, and sound options. Supported aspect ratios include 16:9, 9:16, 1:1, 4:3, 3:4, 2:3, and 3:2 for different content formats and social media platforms. The dashboard also supports Standard, Pro, and 4K generation modes for enhanced output quality.

2. Create Video

In the Image-to-Video section, you can upload a start image and an optional end image to create smooth animated transitions and AI-powered visual motion effects. You can also add animation instructions by describing camera movement, cinematic effects, scene transitions, or visual styles, or select a default template from the Prompt Library for faster generation.

In the Multiple Shots section, you can create a sequence of up to 4 different video scenes using separate images and prompts for each shot. This helps generate cinematic storytelling videos with smooth scene-by-scene transitions.

Each shot allows you to upload a unique image, add a custom shot prompt, and adjust the individual shot duration to control how long the scene appears in the final generated video.

Before generating, you can customize additional settings such as aspect ratio, video duration, generation mode, and enable or disable Sound (On/Off) to create videos based on your requirements.

After uploading the images and entering the animation instructions, click Generate Video to create the animated video. The generated result will be instantly displayed as a new AI-generated video in the Generation Result section.

3. View Generated Videos

Users can preview, download or manage generated videos directly from the Media Library section. The platform also allows users to instantly share generated videos to connected social media platforms without manually downloading or re-uploading files.

4. Delete Video

Users can delete generated videos directly from the Media Library section. If the deleted video has already been shared on connected social media platforms, the platform also removes the associated social media post and related publishing records automatically.

  • Upload start and optional end images for smooth transitions
  • Use Prompt Library for predefined animation prompts
  • Manage all generated videos from the Media Library
  • Directly share videos to connected social media platforms
