Manage Inquiries

Overview

The **Manage Inquiries** module allows administrators to read and handle user queries submitted via the landing page's contact form. Admins can view complete submission details (Sender name, email, subject, message body, submission time), search/sort entries, copy sender emails, and perform bulk deletion of resolved or spam inquiries.

1. Contact Inquiries Table

The inquiries dashboard lists all submissions with columns that can be dynamically sorted:

  • Name: Name of the person who submitted the inquiry form.
  • Email: The sender's email address with a quick-copy button helper.
  • Subject: Brief subject/topic of the inquiry.
  • Message: A preview snippet of the message (truncated to two lines).
  • Last Updated: The date and time of form submission.
  • Actions: Quick view modal trigger (eye icon) or deletion (trash icon).

2. Inquiry Detail Modal

Clicking the view action opens a slide-in modal displaying the complete submission data:

  • User & Contact: Full name and email address in highlighted metadata cards.
  • Subject Header: The full subject of the query.
  • Message Body: The full text block containing the user's detailed message with formatting preserved.
  • Submission Time: Precise timestamp of when the user submitted the query.
