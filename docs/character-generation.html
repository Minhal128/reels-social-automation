Character Generation

Overview

Character Generation allows creators to design consistent, custom AI personas tailored to specific creative briefs or branding styles. Users can configure names, prompts, negative prompts, choose unique artistic styles, select output resolutions, and organize them with tags. This is particularly useful for generating recurring figures in digital storytelling, social media postings, and marketing campaigns.

1. Designing a Custom Character

To generate a new character, go to the Characters panel. Fill in the required character parameters to define the AI model's generation guidelines:

  • Character Name: Give the character a unique identifier (e.g., "Cyberpunk Pilot").
  • Description: Add brief notes detailing the character's background, clothing, or facial traits.
  • Creation Prompt: Provide a descriptive prompt mapping out the character's appearance, posture, and lighting settings.
  • Negative Prompt: List attributes to exclude from the generation (e.g., blurry, distorted, double faces).
  • Artistic Style: Select from pre-configured visual presets (realistic, anime, cartoon, 3d, illustration, pixel-art).
  • Resolution: Pick the output canvas size (1024x1024, 768x768, 512x512, 512x768, 768x512).

2. Character Workspace & Library

Once generated, characters are saved in the My Characters library. This workspace lets users view all active custom personas in a responsive grid. Users can search by character name, copy descriptions, delete old assets, or instantly share the character to connected channels.
