Prompt Library

Overview

The Prompt Library helps store, organize, and manage reusable AI prompts in one centralized place. It allows users to quickly access frequently used prompts for image generation, video generation, creative writing, and other AI-powered tasks.

Prompts can be categorized for better organization, making it easier to search, filter, copy, edit, and reuse prompts across different AI tools within the platform.

Dashboard

The Prompt Library dashboard displays all saved prompts in a clean card-based layout. Each prompt card shows the category, prompt content, character count, creation date, and quick action options.

The dashboard also includes:
  1. Total prompts count
  2. Total categories count
  3. Search functionality for quick prompt lookup
  4. Category filter tabs for organized browsing
  5. Quick actions on each prompt: copy, edit, delete

Users can quickly manage prompts or create new ones using the Add Prompt button.

1. Add Prompt

Click the Add Prompt button to open the prompt creation modal.

The form includes:
  1. Category : Assign or select a category for prompt organization
  2. Prompt : Add reusable AI prompt content

After entering all required details, click the Create button to save the prompt to the library for future use.

2. Edit Prompt

Click the edit icon on any prompt card to update the category or prompt content. After making changes, click the Update button to save updates instantly.

3. Delete Prompt

Click the Delete icon on a prompt card to remove the prompt from the library. A confirmation prompt appears before deletion to prevent accidental removal. Once deleted, the prompt is permanently removed from the system.

4. Copy Prompt Directly

Click the copy icon on a prompt card to instantly copy the prompt content to the clipboard. This allows quick reuse of prompts across AI tools without manually rewriting content.

  • Reuse prompts across multiple AI generation tools
  • Quickly search and filter prompts by category
  • Organize prompts using categories for better management
  • Copy prompts instantly for faster workflow
