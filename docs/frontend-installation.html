Frontend UI Setup (Next.js)

The Reelease AI Dashboard is a high-performance frontend interface. Built with Next.js 16 and React 19, it leverages Tailwind CSS 4 for styling and Redux Toolkit for robust state management.

01
Install Project Dependencies

Open your terminal in the reelease-ai-next directory and run the following command to link all required modules.

# Navigate to frontend
cd reelease-ai-next

# Install packages
npm install
02
Environment Configuration

The application uses next.config.ts for default environment settings. To customize these for your local setup, create a .env.local file in the root directory.

Environment Variable Description Default (next.config.ts)
NEXT_PUBLIC_API_BASE_URL The core API endpoint for data and AI processing. http://localhost:3000/api
NEXT_STORAGE_URL The base URL used to serve generated images and user uploads. http://localhost:3000

Pro Tip: Ensure the NEXT_PUBLIC_API_BASE_URL points to the /api suffix of your running Backend server.

03
Start Development Server

Launch the Next.js development environment. This project fully supports Turbopack for near-instant compilation.

npm run dev

The dashboard will be live at: http://localhost:3001
